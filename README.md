# Profile Card - Tim SecondChoice

## Cara Menjalankan Project

### 1. Clone Repository

Clone repository dari GitHub ke komputer:

```bash
git clone https://github.com/assyddiqjar/tugas-minggu-ke-4.git
```

### 2. Masuk ke Folder Project

```bash
cd tugas-minggu-ke-4
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Jalankan Project

```bash
npm run dev
```

### 5. Buka di Browser

Setelah server berjalan, buka alamat yang muncul di terminal, biasanya:

```text
http://localhost:5173/
```
